# Мой Чек — Персональный трекер покупок и расчет корзины в магазине

Удобное веб-приложение для составления списка покупок и мгновенного подсчета общей стоимости корзины прямо в торговом зале перед выходом на кассу.

## ✨ Ключевые возможности

1. **Трёхъязычный интерфейс (Мультиязычность)**:
   - Переключатель языка в виде флагов слева от валюты: **🇷🇺 Русский**, **🇬🇧 English**, **🇲🇪 Crnogorski**.
   - Название приложения переводится синхронно: **«Мой Чек»** (RU) / **«My Cart»** (EN) / **«Moj Račun»** (ME).
   - Все надписи, формы, подсказки, единицы измерения и модальные окна адаптируются под выбранный язык.
   - Вы можете вводить названия товаров на **любом языке** (кириллица, латиница и др.) — введенный вами текст не затрагивается при смене языка.
   - Выбранный язык сохраняется в `localStorage`.

2. **Мультивалютность**:
   - Быстрое переключение валюты в шапке: **₽** (Рубли), **$** (Доллары), **€** (Евро), **¥** (Юани).
   - Мгновенный пересчет всех цен и итоговой суммы.

3. **Два сценария добавления товаров**:
   - **«Запланировать»**: Составление списка перед походом в магазин (название, количество/вес, выбор единицы измерения: `шт`, `кг`, `г`, `л`, `упак`). Есть кнопки быстрого добавления базовых продуктов (хлеб, молоко, яйца и т.д.).
   - **«Вне плана в магазине»**: Моментальное добавление спонтанной покупки с указанием цены и режима расчёта — товар сразу помечается как лежащий в корзине.

4. **Гибкие режимы расчёта стоимости (Crucial Mode)**:
   - **Режим «За 1 ед.» (Mode A)**: Умножает указанную цену на количество/вес (идеально для штучных товаров, банок, пакетов или весовых фруктов с ценой за кг).
   - **Режим «За всё» (Mode B)**: Введенная цифра считается итоговой стоимостью за позицию независимо от веса (идеально для взвешенных продуктов со стикером из отдела гастрономии/мяса, где указана конечная цена).
   - **Умная подсказка для граммов (`г`)**: При выборе граммов приложение предлагает в 1 клик переключиться на режим «За всё».

5. **Мгновенный пересчет в реальном времени**:
   - При вводе или изменении цены/количества сразу пересчитывается подытог строки и общая сумма корзины без перезагрузки интерфейса.

6. **Плавающая нижняя панель (Sticky Bar)**:
   - Крупная итоговая сумма к оплате.
   - Счётчик прогресса («В корзине X из Y» + процентная шкала).
   - Количество оставшихся товаров.

7. **Управление списком и сортировка**:
   - **Автоматическое перемещение в конец списка**: при установке галочки «В корзине» товар сразу визуально отмечается и плавно перемещается в самый низ списка (в секцию «В корзине»). Если снять отметку, товар возвращается обратно наверх к запланированным покупкам.
   - Быстрые фильтры: «Все», «Надо купить», «В корзине».
   - Кнопка **«Сбросить цены»**: снимает все галочки и очищает цены, сохраняя состав списка для следующего похода в магазин.
   - Кнопка **«Очистить всё»**: удаляет весь список с защитой от случайного нажатия (модальное окно).
   - Загрузка демо-примера для ознакомления.

8. **Оптимизация для мобильных устройств и Safari на iPhone**:
   - Размер шрифта всех полей ввода `16px+` (строго предотвращает нежелательное авто-зумирование экрана в iOS Safari).
   - Атрибуты `inputmode="decimal"` для мгновенного вызова числовой клавиатуры с запятой.
   - Поддержка разделителей `,` и `.` (удобно для русской раскладки клавиатуры).
   - Крупные области нажатия (touch targets 44px+) и удобный переключатель под большой палец.
   - Поддержка безопасных зон экрана iPhone (`env(safe-area-inset-bottom)`).

9. **Локальное хранилище (localStorage)**:
   - Все введенные данные, выбранный язык и выбранная валюта сохраняются на устройстве и не пропадают при обновлении или закрытии вкладки.

---

## 🚀 Как запустить и протестировать

Просто откройте файл `index.html` в любом современном браузере:
- **На компьютере**: Дважды кликните по файлу `index.html` или откройте его через Chrome / Safari / Edge / Firefox.
- **На смартфоне (iPhone / Android)**: Запустите локальный сервер (например, через расширение Live Server в VS Code или команду `npx serve`) и откройте полученный адрес в мобильном Safari / Chrome.
